# 🚀 HireTrack – Recruitment Management System

A full-stack Recruitment Management System built using *MERN STACK* to streamline the hiring process for recruiters and job seekers. HireTrack provides an efficient platform for posting jobs, managing applications, scheduling interviews, and tracking candidates throughout the recruitment lifecycle.

---

## ✨ Key Features

### 👨‍💼 Recruiter Module

* Secure Recruiter Registration & Login
* Create, Update, and Delete Job Postings
* Manage Active and Closed Positions
* View Candidate Applications
* Filter and Search Candidates
* Schedule Interviews
* Update Candidate Hiring Status
* Recruitment Dashboard for Tracking Progress

### 👨‍🎓 Candidate Module

* Candidate Registration & Authentication
* Browse Available Job Opportunities
* Apply for Jobs Online
* Upload and Manage Resume
* Track Application Status
* View Interview Details and Updates

### 🔐 Security & Authentication

* Secure Login System
* Role-Based Access Control (Recruiter/Candidate)
* Session Management
* Protected Routes and Access Restrictions

### 📊 Management Features

* Centralized Candidate Database
* Application Tracking Workflow
* Job Listing Management
* Interview Scheduling System
* Real-Time Status Updates

## 🏗️ System Workflow

1. Recruiter creates and publishes job openings.
2. Candidates browse available jobs and submit applications.
3. Recruiters review applications and shortlist candidates.
4. Interviews are scheduled through the platform.
5. Candidate status is updated throughout the hiring process.
6. Final selection decisions are managed efficiently.

## 🚀 Installation & Setup

### Clone Repository

```bash
git clone https://github.com/PranjalAgarwal12/Hiretrack-Recruitment-System.git
cd Hiretrack-Recruitment-System
```

### Configure Database

Create a MySQL database and update the database credentials in:

```properties
src/main/resources/application.properties
```

### Run the Project

```bash
mvn clean install
mvn spring-boot:run
```

Application URL:

```text
http://localhost:8080
```
